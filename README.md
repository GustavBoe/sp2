# Semester Project 2

![image](https://i.imghippo.com/files/byzK2264kJE.png)

This is the polished CA for Semester Project 2, for the course Portfolio 2.
List is an auction site, where users can bid on eachothers listings. Each users get 1000 credits when registering, these are displayed in the header of the site.
Some of the improvements made:

- Fixed error handling. Users are now redirected rather than being stuck.
- Removed redundant console logs.

## Getting started

1. Clone the repo:

```bash
gh repo clone GustavBoe/sp2
```

2. Install the dependencies:

```
npm install
```

### Running

To run the app and see changes as you go, run the following command:

```bash
npm run dev
```

For production, use:

### Building

```bash
npm run build
```
